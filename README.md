## 概要

TTI-SCANは、社会・地域・組織に生じる「歪み（Strain）」を6軸で検出し、  
収束ベクトルの候補を提示するAI支援分析フレームワークです。

> 存在は「規定」ではなく「回転し続けるプロセス」である。  
> 回転が止まれば存在は双極の0に還る。

## 球体モデルと共鳴

物理と精神の合計が球に収束する。球の振動はそれに共鳴するものへ伝わり、  
他のシステムのスイッチを入れる——これがこの宇宙の空間であり生物の営みである。

```
球A の振動
    ↓ 固有振動数が一致する
球B へ共鳴伝播
    ↓
球B の休眠していた軸がスイッチオン
    ↓
球B が新たな振動源になる
```

### メタンモデル（CH₄）との接続

正四面体配置（均衡状態）のH₁に外力ベクトルがかかったとき、  
中心Cを介して残りH₂・H₃・H₄へ応力が伝播する。  
結果として配置の修正が必要になる——これが社会の歪みの構造。

## 歪みの二分類

TTI-SCANは歪みを二種類に分類する。

| 分類 | 定義 | 対処 |
|---|---|---|
| **破壊的歪み** | 球を変形させ崩壊へ向かわせる外力 | 収束ベクトルで修正 |
| **励起的歪み** | 伝播・成長のエネルギー源となる歪み | 活用・設計 |

> 「盗むことが伝承の証となって幸せにつながる」  
> 無知という励起的歪みが、教える・盗む・伝承するという  
> 生命の伝播メカニズムを生む。（2026年4月27日 観察ログ001より）

## TTIの3つの介入メソッド

### M1 — 土俵の再設定
対立している二者の「戦う理由」を変えずに「戦う場所」だけを動かす。  
山賊焼きモデル：松本 vs 塩尻の争いが、信州最高のソウルフードを生んだ。

### M2 — 第三の問いの投入
A対Bの二項対立に「C」の視点から問いを投げることで思考の軸を変える。  
例：「10年後また来たいと思う観光客は何を求めるか？」

### M3 — 記録と増幅
小さな変換を記録し・語り・次の共鳴の種にする。  
このリポジトリ自体がM3の実装である。
