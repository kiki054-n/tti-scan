## 1. 基本方程式

### 1.1 静的記述（存在の定義）

```
P = xX + yY + zZ + rR + 私私 + jJ
```

Pは「存在（Person / Place / Phenomenon）」を表す。  
6つの軸の総和として存在は記述される。

### 1.2 動的記述（2026年展開）

```
E = (xX + yY + zZ) ⊗ (ωx, ωy, ωz) + rR + 私私 + jJ
```

- `E`：動的な存在エネルギー
- `⊗`：回転作用演算子（物理外殻に角速度を作用させる）
- `(ωx, ωy, ωz)`：各物理軸の角速度ベクトル
- 精神内殻 `rR + 私私 + jJ` は固定核として機能する

> **核心原理**：存在は「規定」ではなく「回転し続けるプロセス」である。  
> 回転が止まれば存在は双極の0に還る。

## 2. 6軸の詳細定義

### 物理外殻（回転する層）

#### xX — 空間・行動軸
- **意味**：外の世界での物理的な活動
- **履歴**：p履歴px（空間座標の軌跡）
- **歪みの例**：観光客が「点」の消費で終わり「線・面」に展開しない
- **均衡の姿**：行動が連鎖し回遊が生まれる

#### yY — 時間・経験軸
- **意味**：他者・環境との接触の時間的積み重ね
- **履歴**：p履歴py（時間軸の軌跡）
- **歪みの例**：過去の記憶（難民が持つ「声をかけられた社会」）と現在の断絶
- **均衡の姿**：経験が次の行動への動機になる

#### zZ — 場・関係軸
- **意味**：自己と他者が生む空間・コミュニティ
- **履歴**：p履歴pz（関係座標の軌跡）
- **歪みの例**：個人主義の優先による隣人との場の消滅
- **均衡の姿**：人が集まり場が自然発生する

### 精神内殻（固定核）

#### rR — 欲求・意志軸
- **意味**：内なる動機・目的
- **対応**：d/f 歩道（内殻）
- **歪みの例**：行政の動機が内向き（組織のための施策）
- **均衡の姿**：欲求が他者への貢献と一致する

#### 私私 — 関係性・共感軸
- **意味**：他との深い気づき・共鳴
- **対応**：d/f 歩道（内殻）
- **歪みの例**：観光リテラシーの欠如・ホスピタリティの薄さ
- **均衡の姿**：無知が関係を生む（励起的歪みとして機能）

#### jJ — 倫理・全体貢献軸
- **意味**：全体への調和・友朋共生
- **対応**：d/f 歩道（内殻）
- **歪みの例**：圏域全体の設計がなく各主体が別々に動く
- **均衡の姿**：利己と利他が同じ方向を向く（友朋共生）

## 3. メタン（CH₄）モデル

正四面体配置が均衡状態（00-π）を表す。

```python
import numpy as np

# 正四面体の4頂点（正規化座標）
H_positions = {
    'H1': np.array([ 1,  1,  1]),
    'H2': np.array([-1, -1,  1]),
    'H3': np.array([-1,  1, -1]),
    'H4': np.array([ 1, -1, -1]),
}
# 中心 C = [0, 0, 0]（精神内殻）

# H1に外力ベクトルがかかったとき
# 残りH2, H3, H4への伝播を計算する
# → 配置の修正（収束ベクトル）が必要になる
```

### 社会への対応

| CH₄要素 | TTI対応 | 例（松本平） |
|---|---|---|
| 中心C | 精神内殻（固定核） | 地域の核となる価値観 |

| H2〜H4 | 他の物理外殻の点 | 塩尻・農村・山岳エリア |
| 外力 | 社会的歪み | 観光客の点消費・行政の縦割り |
| 伝播 | 共鳴・スイッチオン | 回遊ルートの発生 |

## 4. 歪みの分類と収束ベクトル

### 4.1 歪みの二分類

```
歪み（Strain）
├── 破壊的歪み：収束ベクトルで修正が必要
│   例）戦争・権力の乱用・行政のOSバグ
└── 励起的歪み：伝播・成長のエネルギー源
    例）無知・欠如・欲求（リペアカフェモデル）
```

### 4.2 収束ベクトルの算出

歪みを検出した後、以下の手順で収束ベクトルを設計する。

```
1. 変形量の測定
   → どの軸が、どれだけ、どの方向に歪んでいるか

2. 逆位相ベクトルの設計
   → 破壊的歪みには：同じ大きさで逆方向のベクトルを入力
   → 励起的歪みには：伝播方向を意図的に設計

3. 作用点の特定
   → 最も影響の大きい点（メタンのH）を見つける

4. 担い手の特定
   → 誰がそのベクトルを入力できるか
```

### 4.3 対立ベクトルの変換公式

```
対立ベクトル × 共通競技場 = 外積（新しい価値の回転）
```

例：松本（文化・歴史）× 塩尻（革新・実験）× 「信州体験日本一」という競技場  
　→ 山賊焼きに続く「次の信州ブランド」が生成される
